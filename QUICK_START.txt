1️⃣  УСТАНОВИ ЗАВИСИМОСТИ

    pip install -r requirements.txt

2️⃣  СОЗДАЙ TELEGRAM БОТА

    • Открой @BotFather в Telegram
    • Отправь: /newbot
    • Введи название: "My Price Bot"
    • Введи username: "my_price_sync_bot"
    • СКОПИРУЙ ТОКЕН!

3️⃣  НАСТРОЙ .env ФАЙЛ

    cp .env.example .env
    nano .env

    Вставь свой токен:
    BOT_TOKEN=1234567890:ABCdefGHIjklMNOpqrsTUVwxyz

4️⃣  ЗАПУСТИ БОТА

    python run_bot.py

5️⃣  ОТКРОЙ БОТА В TELEGRAM

    • Найди своего бота по username
    • Отправь: /start
