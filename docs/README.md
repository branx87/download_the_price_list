## О проекте

### Цель проекта

Автоматизация синхронизации прайс-листов поставщиков электротехнического оборудования:
- Загрузка прайсов с сайтов вендоров
- Парсинг различных форматов Excel
- Сравнение с текущими ценами в БД
- Уведомление об изменениях через Telegram
- Генерация отчетов

### Поддерживаемые вендоры

- KEAZ - Курский электроаппаратный завод
- OWEN - Приборы автоматики
- EKF - Электротехническая продукция
- IEK - Светотехника и электрооборудование
- DKC - Кабеленесущие системы
- CHINT - Электротехническое оборудование

### Ключевые особенности

**Архитектура:**
- Clean Architecture + Domain-Driven Design
- SOLID принципы
- Dependency Injection
- Паттерны: Repository, Strategy, Factory

**Технологии:**
- Python 3.11+
- python-telegram-bot 20.0+
- SQLAlchemy 2.0+
- pandas для обработки Excel

**Функции:**
- Автоматическая загрузка прайсов
- Интеллектуальный парсинг различных форматов
- Отслеживание изменений цен
- Telegram интерфейс
- Генерация Excel отчетов

## Участие в разработке

### Требования к коду

- Следуйте архитектурным принципам проекта
- Пишите тесты для нового функционала
- Используйте Black для форматирования
- Соблюдайте type hints
- Документируйте публичные API

### Процесс контрибуции

1. Fork репозитория
2. Создайте feature branch (`git checkout -b feature/amazing-feature`)
3. Напишите код и тесты
4. Убедитесь что все тесты проходят (`pytest`)
5. Отформатируйте код (`black .`, `isort .`)
6. Commit изменения (`git commit -m 'feat: add amazing feature'`)
7. Push в branch (`git push origin feature/amazing-feature`)
8. Создайте Pull Request

### Стиль коммитов

```
<type>(<scope>): <subject>

<body>

<footer>
```

**Типы:** `feat`, `fix`, `docs`, `style`, `refactor`, `test`, `chore`

**Примеры:**
```
feat(vendors): add support for NEW_VENDOR
fix(parser): handle empty price values
docs: update deployment guide
```
