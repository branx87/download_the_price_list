# Функциональность проверки актуальности прайсов

## Обзор

Добавлена новая функция для проверки изменений в прайс-листах **без обновления базы данных**. Это позволяет:

- Узнать дату последнего обновления прайса в БД
- Сравнить текущий прайс с новым файлом
- Получить детальную статистику по изменениям
- Принять решение о необходимости обновления

## Команда /check

### Использование

1. Отправьте `/check` в чат с ботом
2. Выберите вендора из списка
3. Получите подробный отчет об изменениях

## Архитектура

### Новые классы

1. **PriceChange** (`domain/entities/price_comparison.py`)
   - Информация об изменении цены одной позиции
   - Свойства: `price_diff`, `price_diff_percent`

2. **PriceComparisonResult** (`domain/entities/price_comparison.py`)
   - Результат сравнения прайс-листов
   - Содержит статистику и детальные списки изменений
   - Свойства: `max_price_increase`, `max_price_decrease`, `avg_price_change_percent`

### Новые методы

1. **SqlRepository.get_vendor_last_update()**
   - Возвращает дату последнего обновления вендора
   - Учитывает нормализацию имен (OWEN/ОВЕН)

2. **SyncService.check_price_changes()**
   - Загружает и парсит новый файл
   - Сравнивает с текущими данными в БД
   - Возвращает `PriceComparisonResult` без изменения БД

### Обработчики бота

1. **check_command()** - обработчик команды `/check`
2. **button_callback()** - расширен для обработки `check_{vendor}` кнопок

## Принципы реализации

- **ООП**: Каждая сущность инкапсулирована в отдельном классе
- **SOLID**: Разделение ответственности (Repository, Service, Entities)
- **KISS**: Простая и понятная логика без избыточности
- **DRY**: Переиспользование существующих компонентов (downloader, parser)

## Отличия от /sync

| Функция | /check | /sync |
|---------|--------|-------|
| Загрузка файла | ✅ | ✅ |
| Парсинг файла | ✅ | ✅ |
| Сравнение с БД | ✅ | ✅ |
| Обновление БД | ❌ | ✅ |
| Создание отчета Excel | ❌ | ✅ |
| Статистика изменений цен | ✅ (детальная) | ✅ (базовая) |

## Использование в коде

```python
from domain.services.sync_service import SyncService

# Создать сервис
service = create_sync_service('KEAZ')

# Проверить изменения без обновления БД
result = service.check_price_changes('KEAZ')

# Получить статистику
print(f"Новых позиций: {result.new_items_count}")
print(f"Изменений цен: {result.updated_items_count}")
print(f"Средний процент изменения: {result.avg_price_change_percent:.1f}%")

# Проверить, есть ли изменения
if result.has_changes:
    print("Требуется обновление!")
```
