# Добавлен вендор SE (Систем Электрик / Schneider Electric)

**Date:** 2026-04-27 14:00
**Files:** vendors/registry.py, bot/handlers.py, adapters/parsers/excel_parser.py, domain/services/data_normalizer.py
**Severity:** low

## Problem

Прайс-лист Систем Электрик ("Тариф АО СЭ ...xlsm") не мог быть загружен через бота — вендор SE не был зарегистрирован.

## Root Cause

Формат файла имеет две особенности, которые требовали минимального расширения ExcelParser:
1. Название колонки цены содержит дату (меняется каждый прайс): "Тариф \n14.11.2025, Руб, \nза единицу тарифа, \nбез НДС"
2. Единицы измерения записаны как "За штуку" / "За упаковку" / "За метр" — не было в UNIT_MAPPING
3. Колонка storage читалась только аналитически, но не записывалась в PriceItem

## Solution

- `ExcelParser._find_col()` — новый хелпер: сначала точное совпадение, затем поиск по подстроке (без учёта регистра). Позволяет искать price-колонку по "без НДС" вместо полного изменяемого имени.
- `ExcelParser._to_price_items()` — все колонки теперь ищутся через `_find_col`, добавлено чтение `storage` и передача его в `PriceItem`.
- `DataNormalizer.UNIT_MAPPING` — добавлены: 'за штуку'→'шт', 'за упаковку'→'упак', 'за метр'→'м', 'упак'→'упак'.
- `registry.py` — добавлен VendorConfig 'SE': лист 'Тариф Москва' (паттерн), header_row=2, partial-match колонки.
- `handlers.py` — добавлен ключ 'ао сэ'→'SE' в _FILENAME_VENDOR_MAP.

Результат теста: 15 375 позиций, единицы {шт, упак} — корректно.

## Prevention

- `_find_col` — теперь стандартный способ поиска колонки для всех вендоров. Помогает при изменяемых именах (дата, версия).
- Новый вендор с partial-match колонками: указывать уникальную подстроку (не 'Тариф' — там два столбца, а 'без НДС').
- Для вендоров с UploadDownloader: добавить ключевое слово в `_FILENAME_VENDOR_MAP` (ключ должен быть ≥3 символов и уникален среди имён файлов).
