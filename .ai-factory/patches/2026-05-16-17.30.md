# Массовый импорт снятых с производства + PriceText через VBA

**Date:** 2026-05-16 17:30
**Files:** bot/handlers.py, bitrix24_bot/handlers.py
**Severity:** low

## Problem

1. Пользователь хотел загружать список снятых позиций файлом, а не вводить по одной.
2. Выяснилось, что надстройка — это VBA-код в Excel, читающий поле PriceText из Total_Price. PriceText теперь устанавливается в 'Снят с производства' при пометке (см. патч 2026-05-16-17.00).

## Solution

**Telegram (bot/handlers.py)**:
- В `upload_price_handler`: если имя файла содержит "снят" или "disc" — файл обрабатывается как список снятых, вызывается `_handle_discontinued_upload`
- Новая функция `_handle_discontinued_upload`: читает .xlsx/.csv с колонками Vendor|Article|Replacement, пропускает строку заголовка если первая ячейка не совпадает с именем вендора, вызывает `mark_as_discontinued` для каждой строки

**Bitrix24 (bitrix24_bot/handlers.py)**:
- Команда `пометить-список` + многострочный ввод (каждая строка: VENDOR АРТИКУЛ ЗАМЕНА)
- Новая функция `_do_disc_batch`: парсит строки, вызывает batch mark в executor

## Prevention

При добавлении feature с ручным вводом одного элемента — сразу добавлять batch-вариант, т.к. пользователь обычно работает со списками.
