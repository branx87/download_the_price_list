# Интеграция с Bitrix24 чатом (webhook-бот + алертер)

**Date:** 2026-05-14 17:00
**Files:** adapters/bitrix/bitrix_api.py, bitrix24_bot/main.py, bitrix24_bot/handlers.py, config/settings.py, .env.example, requirements.txt
**Severity:** medium

## Problem

Бот управлялся только через Telegram. Не было возможности запускать синхронизацию
и получать статус прямо из чата Bitrix24. Также отсутствовала отправка алертов
в групповой B24-чат.

## Root Cause

Функциональность просто не была реализована — проект начинался как Telegram-бот.

## Solution

Добавлена интеграция с Bitrix24 по образцу проектов lunch_bot и integration-1c-bitrix:

**1. `adapters/bitrix/bitrix_api.py`**
- `BitrixBotAPI` — отправляет сообщения через `imbot.message.add` (от имени бота)
  и `im.message.add` (от имени REST-пользователя)
- `BitrixAlerter` — шлёт сообщения в фиксированный групповой чат через `im.message.add`

**2. `bitrix24_bot/main.py`**
- FastAPI-сервер на порту `B24_BOT_PORT` (по умолчанию 7778)
- Принимает POST `/webhook/bot` от PHP-relay (BotWebhookRelay)
- Проверяет токен из заголовка `X-Webhook-Token`
- Парсит `data[PARAMS][...]` form-data и вызывает handlers.handle_message

**3. `bitrix24_bot/handlers.py`**
- Доступ только для пользователей из `B24_ADMIN_IDS`
- Команды: помощь, статус, синхронизировать, проверить, sync_all, sync_{VENDOR}, check_{VENDOR}
- Долгие операции (sync/check) запускаются как `asyncio.create_task` →
  возвращают "⏳ запущено" немедленно, результат отправляется через `BitrixBotAPI.send_message`
- Статус читается напрямую из БД через `SqlRepository`

**4. `config/settings.py`**
- Добавлены: BITRIX_REST_URL, BITRIX_BOT_ID, B24_BOT_PORT, B24_WEBHOOK_TOKEN,
  BITRIX_ALERT_CHAT_ID, B24_ADMIN_IDS

**5. `requirements.txt`**
- Добавлены: fastapi>=0.110.0, uvicorn>=0.29.0, httpx>=0.27.0

## Prevention

- Долгие фоновые задачи (>2с) в webhook-серверах всегда запускать через `asyncio.create_task`,
  иначе PHP-relay получит таймаут и посчитает запрос неуспешным
- Для отправки ответов из фоновых задач нужен BITRIX_REST_URL + BITRIX_BOT_ID
- PHP-relay (BotWebhookRelay.php) уже реализован в integration-1c-bitrix и пригоден для переиспользования
